# Pizza Sales Performance Dashboard

## Project Overview

An interactive dashboard developed to analyze pizza sales performance throughout 2015. The project provides insights into revenue, orders, product performance, and customer ordering patterns through interactive data visualizations.

## Dashboard Features

The dashboard consists of three main sections:

- **Overview:** Total revenue, orders, pizzas sold, average order value, and monthly sales trends.
- **Productivity & Trends:** Orders by hour, day of the week, and monthly performance.
- **Pizza Performance:** Top and bottom-performing pizzas, revenue by category, and pizza size analysis.

## Key Insights

- Total Revenue: **$817,860.05**
- Total Orders: **21,350**
- Total Pizzas Sold: **49,574**
- Average Order Value: **$38.31**
- July recorded the highest monthly revenue.
- Friday was the busiest day of the week.
